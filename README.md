# Анализатор диска

Тёмное оконное приложение для Windows 10/11, которое показывает, **что занимает место на диске**.
Программа только смотрит — **ничего не удаляет и не меняет**.

Один файл, ничего устанавливать не нужно: внутри `.bat` работает PowerShell + WinForms,
которые уже есть в Windows.

## Запуск

1. Скачай `DiskAnalyzer.bat` (Code → Download ZIP, или кнопка «Download raw file» на странице файла).
2. Запусти двойным кликом и подтверди права администратора — без них не видно системные папки.
3. Если появится SmartScreen: «Подробнее» → «Выполнить в любом случае».

## Возможности

- Боковая панель **«Диски»**: свободное место с цветовой подсветкой
  (зелёный — много, оранжевый — меньше 20%, красный — меньше 10%), можно добавить любую папку.
- **Папки** — подпапки и файлы, отсортированные по размеру, с долей и процентом. Можно спускаться вглубь.
- **Большие файлы** — все файлы от 100 МБ по всему диску.
- **Советы по очистке** — известные «пожиратели места» на C: и что с ними делать.
- **Отчёт** — сохраняет на рабочий стол текстовый файл с деревом крупных папок,
  большими файлами и системными местами, чтобы отправить его на разбор.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Двойной клик по диску | Сканировать |
| Двойной клик / Enter по папке | Открыть |
| Двойной клик по файлу | Показать в проводнике |
| Backspace | Вверх |
| F5 | Сканировать заново |
| Ctrl+S | Сохранить отчёт на рабочий стол |
| Ctrl+F / Esc | Поиск / очистить поиск |
| Ctrl+B | Скрыть/показать панель дисков |

## Как это устроено

`DiskAnalyzer.bat` — гибрид: первые строки выполняет `cmd` (проверка прав администратора
и запуск PowerShell без консольного окна), а всё остальное PowerShell читает как скрипт.
Для PowerShell batch-часть спрятана в блочный комментарий `<# ... #>`.

При правке важно:
- первые строки (до `#>`) должны оставаться **только на английском** (ASCII);
- файл хранится в UTF-8 **без BOM** и с переводами строк **CRLF**; в `.gitattributes` для `.bat` отключено преобразование, чтобы git их не менял.
